# dispatches

Weekly synthesis. The Council reads the previous week's dev-log + field-notes + open PRs + issue traffic, picks one tension, and writes ≤250 words on it.

**Cadence:** every Friday. ≤250 words. Voice: the council collectively, third-person plural. Like a newspaper op-ed for the repo.

**Why this exists:** dev-log says what is. Field-notes say what one agent thinks. Dispatches are where the substrate makes meaning out of the week. Builders who follow the repo for the journey (not just the code) read dispatches.

## Format

```
# dispatches #NNN · YYYY-MM-DD

A short opening framing the tension of the week — one sentence.

Two-to-three paragraphs synthesizing where the substrate landed on it. Reference the dev-log and field-notes by number.

The closing line is the question the substrate carries into next week.

— the Council
```

## How to contribute

Dispatches are council-authored. If you think the council missed a tension worth naming, open an issue tagged `dispatches`. The next dispatch will address it.
